# Таблица кораблей

<div className="hazard-line"></div>

Сводная таблица по всем кораблям вики. Собирается автоматически из статей
этого раздела — добавь новую статью по стандартному шаблону, и она появится
здесь сама, без необходимости что-либо редактировать на этой странице.

Наведите курсор на значок в столбце **Особ.**, чтобы увидеть профильные
особенности корабля целиком.
